# フィギュアの立体・材質と接触から続く破砕（#111）

2026-11-03 JST。はねさんの試遊後の採用依頼を実装する。事前技術設計と受入条件は [Issue #111](https://github.com/hane-san/SRPG-01-FEstyle/issues/111)。親 #102/#104 の美術最終決定・実機評価は別途残す。危険度 high（頂点形式、投影・指示点、演出と音の同期を横断）。

## 見た目と入力

- 01/04の工業幻想・古典ファンタジーを更新。胸甲、肩、顔・鼻・顎・耳、肘・膝と手足、兜・武具、馬の筋肉・首・口と騎乗姿勢を造形。低い円形台座、接地影、方向のある影で模型の重量と接地を示す。上端の駒は画面外へ頭が切れないよう縮小する。
- 楕円体・円柱の側面は滑らかな頂点法線、建築や面取りは面法線。頂点形式は position3/normal3/RGBA4/roughness1/metalness1（12 float、48 bytes）。金属・真鍮の反射と粗い布・革・肌を区別する軽量な材質シェーダ。外部モデル、テクスチャ、ライブラリ、音源は追加しない。
- 北を上に固定。高さの投影係数を0.72から1.02へ変更し、側面・体の厚みを強める。地面の投影・セル座標・スクロール領域は保持。演出がカメラを動かさない。
- 指示点は実際に送信した動的三角形へ投影し、重なる場合は描画と同じ奥行で手前を選ぶ。台座・足元は従来の地面セルにも対応。経路編集中の本人、半透明経路プレビュー、撃破中の残像は新しい目的地を遮らない。

## 描画資源と負荷

- 1 canvas当たり context1/program1/VBO2。静的地形は全盤面をキャッシュし、動的な駒と影は表示領域＋2セルの余白へ絞る。スクロール時に駒を再描画し、地形は再生成しない。実験室は独立canvasを閉じると資源を明示解放する。
- 同じVBO/シェーダで地面への影を投影。stencilがある場合だけ影を描き、重なる面を同じ影の中で何度も暗くしない。静的更新時は4 draw calls、キャッシュ利用時は2。stencilがない場合は形状・材質を保って影のみ省略。
- GL画像はDPR最大1.5、1024×2048以内。動的画像には表示領域の原点を持たせ、2D側の地面・HP・経路と同じ世界座標へ合成する。奥行の分母には全盤面寸法を使うので、盤面の南側でも切れない。
- 検証環境のChromiumソフトウェア描画では04の1.9倍表示、可視駒約3万三角形で更新約40msの測定例。描画範囲・駒数・端末で変わる。初回地形生成・拡大変更は重く、iPhoneの速度や60fpsを保証する測定ではない。WebGL利用不可・context lossは既存2Dへ復帰し、確定済み命令の解決を続ける。

## 打撃の標準を更新

- 最新依頼の `impact` を標準にする。従来 #101 の数字だけを先に150ms見せる `crystal` と `current`/`weighty` は比較候補として保持する。本編も標準演出を使い、独立試遊は選択した候補を実験室にも引き継ぐ。
- 既存の構え時間（通常200ms、弓/砲320ms）内で、初めの約62%をため、残りで踏み込み・武器を振る。接触時に打撃SE・ダメージ数字・最初の拡大宝石の破砕を同時開始する。新しい数字単独待ちは0ms。
- 実損失HPの個数だけ破砕。1〜2粒は110ms、3〜4粒は85ms、5〜6粒は65msごと。最初の26ms（強打42ms）の停止は最初の破砕間隔に内包し、SEの次の破砕と画の開始を合わせる。各粒は接触時刻からの絶対期限で進め、メッシュ生成や遅いフレームの時間を粒ごとに上乗せしない。威力2で残HP1なら1粒。反撃は別observer、治療は再生演出のまま。
- Fast/Reduce Motion/背景化は拡大連鎖を省き、従来の短縮時間を保持。P2の短い読取間隔は通常速度だけ。音声失敗・SE OFFは命令解決を妨げない。
- 構えの短い擦過音と、接触の低い胴鳴り・金属/木質の衝撃を分離。弓、魔術、槍/騎兵、砲撃、重装への接触を帯域と減衰で区別する。新しい接触では破砕ノイズを少し抑えて重なりの余白を作る。原合成音のみ、BGMは変更しない。

# 2・3案の美術をGBA以上の表現密度へ（2026-10-31、実装準備）
## 決裁
プロデューサー：「グラフィックや世界観違いバージョン、2つめのスチームパンクと3つめのリアル版はもっとはっきりわかるGBA以上のグラフィックスにしてほしい」。
現行の簡素な手続き描画は仮素材であり、今回の要求を満たした完成美術ではない。1＝現行、2＝スチームパンク、3＝写実寄りファンタジーを同一戦況で比較。3は過去のGBA〜SFC FE的な要望の延長と解釈し、写真風や3D化を必須にしない。目標はハードの解像度・色数の再現ではなく、完成した携帯機SRPG以上を目指す造形/材質/陰影/動き。達成判定は人間の試遊で行う。

## 絵作りの方向
| 要素 | 2：スチームパンク | 3：写実寄りファンタジー |
|---|---|---|
| シルエット | 配管束、段差のある工場、巨大制御門、護岸・桁橋 | 石造城、自然な起伏、岩稜、樹冠、城下の屋根 |
| 材質と光 | 真鍮の縁、鋼板/リベット、煤、湿った石、琥珀灯と寒色の水 | 石積みの継ぎ目、革/布/鋼、植生の高さ、土と水の境界、統一した日光 |
| 駒 | 作業装備/防護面/機械弩・砲架。兵種ごとの固有の形 | 自然な頭身と重心、兜/鎧/盾/槍/弓/馬/衣。棒人形状の簡略化から進める |
| 動き | 細い蒸気、灯の小さな揺れ、水面、武器の機構 | 立ち姿の微動、旗、弓/槍/布の追従、水面 |
| 景観 | 運河と工場のスケール差、構造が連続する橋と門 | 自然地形と人工物の対比、橋頭堡/城壁が地形へ接地 |

色替え・ノイズ増量・同一駒へのゴーグル追加だけで完了にしない。地形の輪郭/構造と駒の造形も別にする。魔術師は回復特化という役割が分かる装備とし、攻撃魔法の予備動作を付けない。HP6結晶、兵種札、青赤の識別は共通の読みやすいレイヤー。

## 実装と表示
- 同じ01の橋/森林/城と04の渡河/要塞を比較する。まず橋・城・森・重装/騎兵/魔術師を含む代表場面を完成密度で作り、承認前でも試遊で比較できる状態にする。その後全地形/全兵種/行動済・被弾・撃破へ展開。代表場面だけを完成版と呼ばない。
- 32px座標のゲームモデル、タップ判定、地形意味、通路、駒の占有を維持。絵の上端や影が隣接マスへ伸びても、足元/所属/選択輪で占有を読み取れること。飾りの壁を通行不能の壁に見せない。
- 48/64px等の高密度素材やアトラスは候補。素材解像度の増加だけを品質向上とみなさず、通常のスマホ全幅表示でも輪郭/面/材質差を読む設計にする。小さな画面に細部を潰して「拡大すれば見える」で済ませない。鑑賞ズームは明示操作のみ、比較中に勝手にズームしない。
- pixel artとして輪郭/明暗面を整える。意図しない補間ぼけや線幅の揺れを避ける。既存の地形/盤面キャッシュ契約を確認し、高解像度サーフェスが必要なら試遊限定の設計変更としてメモリ実測と上限をPRへ記録。無制限のマップ全面レイヤー追加は禁止。原則アトラス＋共有描画で、静止画面の再生成を毎フレームしない。
- 素材はオリジナル。既存ゲームのスプライト/地形/ロゴ/固有意匠を流用しない。生成素材を使う場合も透過/グリッド/輪郭/光源/兵種整合を整えて実ゲームへ統合し、コンセプト画像だけで納品しない。
- 効果は局所的に。強い画面全体の点滅/常時蒸気/常時揺れで盤面を騒がしくしない。Reduce Motionと低負荷表示を設け、命中/HP変化の視認性を優先する。
- 1はそのまま保存。2/3は別美術profileとして即切替。AI/数値/配置/音/入力を同時に切り替えない。各profileの部品が欠けた時に黙って1へ混在せず、開発検査で検出する。

## 受入
1. 同じ戦況/カメラ/倍率、同じ兵種入りで3案を並べるスクリーンショットとゲーム内の切替。通常全幅と拡大の両方で2/3の造形・材質・陰影が明確に異なる。
2. 01/04の水/床/街道/森/壁/橋/城/村、全兵種・両陣営/行動済/低HPを確認。森は移動コストだけで、防御ボーナスを暗示しない。
3. 選択/経路/射程/危険/予告/HP/対象を重ねた実操作でも見失わない。描画だけの更新前後でゲーム状態/カメラ/セーブが完全一致。
4. ブラウザ320/360/390縦・844横、通常倍率・拡大、1→2→3→1、スクロール/自軍へ/ミニマップ/再試行/本編復帰、通常/高速/Reduce Motion/低負荷を確認。描画時間・キャッシュ更新・メモリを旧版と同条件で測る。
5. 人間の美術評価「GBA以上に見えるか」は未検証として残す。ピクセル差分があるだけ、色数が増えただけ、CIが成功しただけで達成としない。

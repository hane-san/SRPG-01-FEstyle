# 2つの可遊ポリゴン3D（2026-11-02、#109）

採用元 #102 / #104。01/04の独立試遊に、現行2D・工業幻想3D・古典ファンタジー3Dを実装する。本編の世界観・3D化の正式決定や、人間の美術品質評価を済ませたという意味ではない。

## 遊び方

- `?sample=01&style=industrial` / `?sample=01&style=fantasy`。04は `sample=04`。
- 試遊メニューの3案を同じ戦況で切替。1は現行2D、2/3は実際のWebGLポリゴン描画。試遊は本編の保存を読み書きしない。
- AI・打撃感・移動操作は独立の設定。テーマ曲は実装済みNo.43–46を共用し、連動OFFでは従来マップ曲に固定できる。画風切替でBGMを勝手にONにしない。
- 出撃、経路、敵へのスライド確定、取消、P3、予告、ターン終了は共通。命令中・指保持中の画風変更は拒否。明示的なズーム/移動以外でカメラを動かさない。

## 実装した造形と動き

外部モデル・テクスチャ・CDN・新規実行依存なし。独自の立体メッシュを頂点・面法線・色・depth buffer・方向光/環境光で描く。2Dの画像を斜め変形したものではない。

| 要素 | 工業幻想 | 古典ファンタジー |
| --- | --- | --- |
| 戦場 | 工場棟、煙突、配管、真鍮の接合部、琥珀窓、護岸/金属橋、排水口 | 樹冠と幹、岩、石積み、城門/屋根/旗、木橋と欄干、村の家 |
| 軽装・重装・槍 | 機械装備、ゴーグル、防護板、盾・長柄 | 外套、兜、胸甲、盾・槍・剣 |
| 弓・騎兵 | 機械弩、馬体と手綱/騎手 | 弓と弦/矢筒、馬体と鞍/騎手 |
| 魔術師・砲兵・賊 | 治療具、砲身/反動、車輪/砲架、頭巾と斧 | 杖/衣、弩砲、車輪/砲架、頭巾と斧 |

7味方兵種＋敵賊、両陣営、上級の肩飾り、行動済を描き分ける。HP6/兵種/所属/行動済の高コントラスト表示は共通オーバーレイ。森林や建築の前にも駒とHPを合成し、戦術上必要な駒を隠さないカットアウェイ表示にする。

`view.motion/animation/impact/ghost` から、経路に沿う足運びと向き、馬の脚、車輪、武器の構え/振り/弩の引き、被弾/盾の受け、治療、砲架の反動、倒れ/消失を描く。呼吸は上半身だけを弱く動かし、足元を浮かせない。Fast/Reduce Motionは関節の大きな動きと環境微動を停止。独立タイマーで攻撃結果を計算せず、共通playbackの接触→数字→宝石/音→反撃を維持する。

## 投影・入力・資源

- 北を上に固定した正投影。world Xは横、Yは高さ、Zはマップの縦方向。画面は `x=X*tile`, `y=(Z−0.72Y)*tile`。地面Y=0への逆投影を `polygon-space.js` に集約する。
- 橋の歩行面もY=0。厚みや基礎、水面はその下へ、樹木/装備は上へ造形する。地形の見た目で移動コストや高低差ボーナスを追加しない。地面セル中心が2Dと一致するため、切替時の中心/スクロール/ドラフトをそのまま保持できる。
- 地面と上へ張り出すシルエットの両方を選択対象にし、同じ足元セルへ対応。広い円を隣の駒へ重ねる方式ではない。既存の44px命令ボタン/固定ドックは維持。
- 1描画canvasにつきWebGL context1、program1、static/dynamic buffer各1。静的地形はキャッシュし、通常は動的ユニットの1 draw callのみ。地形の再構築時だけ地形と駒の2 calls。CPU側に地形色のsnapshot1枚を保持し、再描画時の地形再送を避ける。従来2Dの32px二層キャッシュは維持。
- DPR上限1.5、GL描画は最大1024×2048pxに制限。表示上のセル座標や既存ズームは変えない。idleは最大8fps、指保持/演出中は既存playbackのフレーム、背景/モーダル中はidle停止。
- 2D切替・実験室閉鎖・pagehideでbuffer/program/contextを解放。context loss/生成失敗は戦況と確定命令を維持して2Dへ明示復帰し、メニューから3Dを再試行可能。

- Node：投影/逆投影と端セル、頭への指示点、隣セルの誤選択、両世界の地形/面法線、全兵種/陣営/上級の有限メッシュ、共通観測と関節・治療/反動・撃破、Reduce Motion、ゲーム状態不変。
- Chromium：320/360/390縦・844横、01/04×3案の同じ出撃/ターン進行の最終state一致、切替/スクロール/選択/ドラフト/本編save不変、実際のWebGL生成・buffer/program数を検証。
- 通常速度の実験室6場面で動的頂点列の変化と終了結果を確認。閉鎖後は実際のGL buffer/programがメイン分の2/1へ戻る。攻撃確定後・再生中のcontext lossでも共有engineの攻撃/反撃結果と一致し、入力ロックが解除される。WebGL不可時の明示2D復帰と3D再試行も検査。
- `npm run check`、`npm run test:browser`、`npm run simulate` と最終SHAのCI/Pagesの実測結果はPRへ記録する。simulateの既存39方策は変更前と完全一致。テスト削除/skip/期待値弱体化は行わない。

### 性能の読み方と未検証

検証環境はPlaywright1.57.0のChromium143による自動/ソフトウェア描画。初期地形生成/GL描画は数百ms〜1秒超を要し、負荷と描画サイズに依存する。キャッシュ後のフレームと初期化を区別し、実測はPRへ残す。小さな地面の面取りは描画に不要な三角形を省き、鎧/建物の輪郭に造形を配分した。VBO見積はframebuffer・アンチエイリアス・Canvas snapshot等を含まない。

iPhone Safari/WebKit実機、実耳、人間の美術/読みやすさ/操作感/面白さ、独立監査は未検証/未実施。写実感やGBA以上の完成品質、実機60fpsを自動テストや三角形数で達成扱いにしない。今回の3Dは遊んで比較・改良する実装であり、美術の最終完成ではない。

04・390×844・deviceScaleFactor2の自動Chromiumで、地面の不要な面取り削減後を測定。初期GL寸法558×1860、最大ズーム614×2048。下の時間はrenderer内部で、アプリ全体のフレーム時間や実機fpsではない。

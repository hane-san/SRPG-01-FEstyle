# 操作の一貫性を整える試作仕様（#96）

## 最新の決裁・位置付け（2026-10-31）
プロデューサー：出撃時のセリフはいったん不要。予備の駒を選んで普通と同じように自然に動かしたい。味方魔術師は自分から攻撃できない回復特化職。スライド行動とボタン待機が混在するUI、ターン終了を含む直感性/一貫性/テンポを総合検討・調整してほしい。
#92〜#94とPR #95へ追加する実装準備。出撃セリフ不要は確定。具体ジェスチャー/時間値/終了表示は以下の推奨試作で比較・調整する。本編ルール変更の採用ではない。
## 現行で確認した不整合
app.beginMapGestureは通常移動に200ms保持、条件によりopenDraft→待機ボタン、一方sortieOriginの移動は直接commit。playbackのdeploy専用210ms出現＋440ms字幕待ち。味方魔術師でもpanelに使えない攻撃ボタンがある。askEndは未行動数だけで確認し、P3温存や出撃余力の意図が伝わりにくい。
## 採用する目的・推奨試作
1. 出撃字幕/専用停止を撤去。普通と同じ経路移動/攻撃へ直結。deploy観測・出撃枠・保存atomic性は維持。金属音を残すなら普通の動きへ重ねる短い一音程度、追加待ちなし。攻撃SE/FXで足す重みと出撃の待ちを混同しない。
2. 盤上/予備/帰還後は共通のdraft→合法性判定→release→commit。推奨A：意図したドラッグで合法な空き終点を選び離すと移動待機、合法な敵上なら攻撃。その場待機は起点の短い意図的保持→静止準備表示→離指（200msを開始候補）。単なるタップは選択/解除だけで資源を消費しない。別案B：空き終点/起点とも共通保持200ms→離指。同条件でA/Bの誤操作率と入力時間を比較し、合う方へ。旧操作も比較用に戻せる。全操作を無理にスライド化しない。
3. 指保持中は移動待機/攻撃/静止治療/静止砲撃の結果が分かる一行とHP/反撃/支援候補。保持未成立・非法終点・画面外・別敵・二本指/cancel時は最後の合法地点に勝手に確定しない。地図パンと区別し、元のdraft/カメラへ戻す。
4. 回復特化UI：魔術師は使用不能な攻撃操作を主操作から外す。動いたら「移動待機・このターンP3治療なし」、静止なら「P3治療準備」、弾薬0/温存/対象なしを区別。現時点候補とP2後の実対象は異なる。味方に滑らせて即時治療できるようにしない。P3は隣接1隊/HP+2/静止/有限弾薬/反撃なしを維持。砲兵も同じUI文法。手動回復対象指定や移動後回復は別提案。
5. ボタン/キーボードは代替として残し、ジェスチャーと同じcommandへ。待機のために必ずボタンへ戻る構造を解消。直前移動Undo、単独取消、エラー後復帰、左手/ズーム/横画面/端スクロールも一貫させる。
6. ターン終了：専用44px以上の固定位置ボタン。「敵フェーズへ」と盤上未行動nを明瞭に。予備は未行動に数えず、出撃余力は別に短く表示。全盤上部隊行動済なら1タップ、残るなら同じ固定dock内などに小さな確認＋未行動部隊への戻り口。未操作隊は静止待機になり専門職は条件を満たせばP3準備する旨、温存/弾薬0も正確に。出撃余力だけで毎回確認を強制しない。0隊でも自動出撃/自動終了せず、全員行動済で勝手に敵番へ進まない。取消で何も消費しない。連打/演出中/指保持中に二重P2へ入らない。
## 検証・不変条件
状態遷移表（idle/select/route/target/armed/commit/play/cancel）と、同じ出撃/移動/攻撃/静止命令を各入力から実行した状態一致をテスト。通常兵/回復/砲兵、T1二隊/後続一隊/5隊上限、帰還再出撃、保存読込、無味方/予備のみ/全員済/温存/弾薬0、P4危険中の終了、Fast/Reduced/SE on-off、320/360/390縦/844横・左右配置・小タイル・端パンを確認。
HP6/4フェーズ/決定論/勝敗/全6マップ/ロスト/保存互換/42曲は維持。魔術師数値・移動後P3・手動即時治療は勝手に追加しない。既存回帰は削除せず、旧UIが仕様として変更される検査は旧profileのfixtureで保持し新profileの受入も追加。単に期待値を弱めて通さない。

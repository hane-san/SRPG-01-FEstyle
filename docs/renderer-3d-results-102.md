engine・数値・地形・配置を変更していないため`npm run simulate`は今回の変更条件に該当しない。`engine.js`・`data.js`・`config.js`・`save.js`・`playback.js`・音楽コードは基準から差分なし。2Dの二層32pxキャッシュ契約も変えていない。

ローカル環境はNode.js 24.19.0、Playwright 1.57.0、Chromium 143.0.7499.0（ANGLE SwiftShader）。CIで取得する公式Chromium 143.0.7499.4とパッチ版が異なる。ローカルの既存04マップのタッチ検査では一度ドラッグが移動せず失敗し、条件・テスト・実装を変えずに再実行すると4画面とも成功した。基準mainの同じ04マップ検査も別サーバーで4画面成功。最終headの公式CIでの確認をローカル結果に置き換えない。

追加の実操作確認：04の味方を選び、矢印キーで2セルの空でない経路を描いてから、実際の比較メニューで2D→3Dを切り替えた。4画面でドラフト・選択・戦況が完全一致し、中心誤差0.05セル未満。これは追加の操作確認であり、独立監査ではない。

## 試遊と残る判断

main統合・公開後の入口：

- [01 工業幻想3D](https://hane-san.github.io/SRPG-01-FEstyle/?sample=01&style=industrial&renderer=webgl)
- [04 ファンタジー3D](https://hane-san.github.io/SRPG-01-FEstyle/?sample=04&style=fantasy&renderer=webgl)

メニューの2D／3Dと画風を切り替え、「細かく兵種の個性があるか」「小さすぎないか」「敵フリックを狙いやすいか」を同じ戦況で比較する。馬の足・弓・盾受け・静止治療・砲撃が読み取れるか、Fast／動きを減らす設定で意味が残るかも試遊項目。

現在は兵種・地形を作り分けた手続きポリゴンによる最初の可遊版。原始形状を組んだだけの技術デモを超える部品と動作を用意したが、写実ファンタジーの美術完成とは扱わない。写実表現の仕上げ、3Dの標準化ははねさんの判断待ち。新しい戦闘規則や段差コスト、セリフ、音楽、出撃停止、自動カメラは足していない。

iPhone Safari／WebKit実機、端末GPUの性能、実際の音の聞き取り、見た目と美術の人間評価、独立監査は未検証。自己監査を独立監査とは呼ばない。

# 予告地点を確認して戻る（#85 / #80-F）

2026-10-26。基準main `f280333b12eb2de0712e1a1b5a7649902d0c52d8`。
既存の画面外P4予告への移動に、元のスクロール位置への復帰を加えた。
危険度medium（表示用カメラと指入力のガード）。エンジン・保存形式・数値は変更しない。

画面外予告をタップすると、確認前のscrollLeft/scrollTopを一時保持して予告地点へ移動する。
同じ予告欄が「元の位置へ戻る」になり、再度押すと正確なスクロール位置へ戻る。
Enter/Spaceにも対応。操作可能なときだけTabで選べる。
予告欄の高さは44px以上で、固定dock・盤面の寸法を動かさない。
警告の音声読み上げ用の通知も維持する。

指保持中と演出ロック中は往復できない。取消そのものでは自動移動しない。
警告リスト/ターン/マップ/画面寸法/ズームの変化、自軍へ戻る・次部隊・ミニマップ等の
別の明示ナビゲーションで、古い戻り先を失効させる。
通常の手動スクロールは戻り先を保持するため、確認先を見回してから元へ戻れる。
カメラ位置は保存しない。命令・出撃枠・戦果に副作用を与えない。

`tests/warning-return-browser.mjs` は320/360/390px縦と844px横で、
砲撃/増援が重なる状態の往復・Enter/Space・保存文字列/状態不変・dock寸法、
自軍へ/ズーム/リサイズでの失効、実際の部隊の指保持と取消、警告なしを検査する。
既存の予告への移動検査は維持した。最初の検査データで存在しない警告種別を使ったため
保存が拒否されメニューが開いたが、実際のspawnへ直して回帰した。城上は出撃用の入力なので、
部隊保持の検査は隣の合法マスへ部隊を置いて行う。

ルール・数値・マップ変更なしのため、今回のsimulateは未実行（対象外）。
本編・サンプルの既存回帰を通す。iPhone/WebKit・実耳は未検証、独立監査は未実施。
夕方は長い03/06で予告確認→元の部隊へ戻る動作が、視線と指の負担を減らすか試す。

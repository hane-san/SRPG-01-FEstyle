# P3専門職化・初回試遊仕様（Issue #26）

> 状態：**PR #27/#31を含むPR #33でmain統合済み**。旧v0.8.0の「全兵種で待機攻撃・回復が可能」を置き換えた現行のP3規則。下記は初回試作時の兵種名を含む記録で、後続の[Issue #68の兵種整理](base-classes-68.md)では旧回復職を魔術師へ統合済み。人間の実機試遊が完了したという意味ではない。

## この試作で確かめること
盤面を見て「進軍する／陣地を構える／負傷兵を退却させる」を考える楽しさが、追加操作なしで発生するか。槍兵や上級職、進退判定は追加しない。

| 味方兵種 | P1での通常攻撃 | P2反撃 | P3 |
|---|---|---|---|
| 剣士隊・盾槍隊・長弓隊・騎兵隊 | 可（従来どおり） | 可（射程内） | なし |
| シューター（砲兵） | 不可 | 不可 | **静止待機で敵1隊に砲撃** |
| 魔道隊 | 不可 | 不可 | **静止待機で隣接味方1隊HP+2** |
| 祈祷隊・救護隊 | 不可 | 不可 | **同上（旧回復職を暫定的に魔術師系として扱う）** |

### 共通の約束
- P1で**1マスでも移動したらP3を使用できない**。出撃時も城から移動したら同じ。通常の移動力自体は制限しない。
- 静止待機しても弾薬0ではP3準備できない。対象なし・回復不要・不発時は弾薬を減らさない。
- P3専門職だけ弾薬最大2。城からマンハッタン距離1以内なら次のターン開始時に弾薬1を補給。
- 砲兵の従来射程は2〜3マス。ダメージは距離2で2、距離3で1（重装軽減・最低1は従来どおり）。
- 魔術師系回復は隣接1マスの負傷味方から1隊を選び、HP+2（上限6）。自分自身・斜めは対象外。
- P1命令は「攻撃／待機」、フェーズ順はP1味方→P2敵→P3味方専門支援→P4予告戦場イベント。P3の対象決定は既存自動選択。
- **敵の魔道隊は既存AIとP2攻撃を暫定維持**。敵一般兵のP3は追加しない。将来の敵魔術・射撃体系は別に整理。
- HP6・城の逐次出撃・最大同時出撃5・ネームド永久ロスト・予告イベント・BGM・スマホ操作・保存キーは変更しない。
- 旧v0.8.0のP1保存を再開するとき、移動・HP・戦闘経過・兵種枠を保存し、旧方式のP3準備だけ安全側に解除する。普通兵の古い弾薬は0に正規化。

## 明示的に採用していないこと
- 槍兵、賊、基本兵種統廃合（祈祷隊・救護隊の存廃も未決定）。
- 「1マス移動ならP3可」、前進と後退でルール差、P3範囲回復、魔法攻撃、敵全軍のP3移行。
- バランスが完成したという主張。HP6の回復減・敵攻撃型魔道隊・砲兵据え付けによって難度や勝率が大きく変わり得る。

## 検証と受入
1. 砲兵のP3射撃、魔術師系のP3単体回復、弾薬・対象優先・補給・多重発火防止をエンジン試験。
2. 通常兵種のP3不発、専門職のP1攻撃拒否・P2反撃なし・移動後P3不可をエンジン試験。
3. 古いv0.8.0保存を再読込して兵種と古いP3構えの不整合を生まないこと。
4. CIの `npm run check` と `npm run test:browser`：6マップ、320/360/390/844px、出撃・保存・移動・砲撃・HP、コンソールエラーを確認。CI通過をiPhone実機の代わりにしない。
5. プロデューサー試遊：防衛戦は陣地固定が強すぎないか、進撃戦では後衛の追従が遅すぎないか、負傷兵を下げるか魔術師を前進させるかが実際に迷う選択になるか。
6. 続く比較案：第2試作として魔術師のみ「1マス移動後P3可」を検討する。ただし今のPRには入れない。

# 敵の混成AI・第一段階（2026-11-02）

採用元は #93 の11月2日追記、実装単位は #107。01/04の独立試遊だけに「混成 v1」を追加する。本編へ適用せず、側面迂回・本編バランスの正式採用・3Dは後続。

## 遊び方と比較条件

- 01：`?sample=01&ai=mixed`、04：`?sample=04&ai=mixed`。試遊メニューの「敵AI」で現行／混成を切り替える。
- 切替は当該ターン開始の同じ盤面から再開。別profileへ切り替えると迎撃の覚醒情報をリセットし、同profileでのやり直しはその開始時の覚醒情報を維持する。位置・HP・命令・敵数・能力は変更しない。
- メニューの「敵の役割・持ち場・発動条件」で敵IDと1始まりの座標を確認。迎撃役を選ぶと感知の点線を表示する。危険域／P2射程概算は最大の移動・射程による保守的表示で、確定被害や役割ごとの行動予言ではない。
- 本編saveを読み書きしない。更新するとT1へ戻り、「本編へ戻る」で元の保存に復帰。画風・音・打撃感は別軸のまま比較する。

## 役割と境界

`trial-profiles.js` の `MIXED_ROLES` をマップID＋敵IDで解決する。兵種や配列順では決めない。未登録IDは従来の `unit.ai` を保つ。

| 役割 | 行動 |
| --- | --- |
| 進軍 | 盤上の味方へ、既存の合法経路と距離場で接近。隠れた予備を追わない |
| 縄張り迎撃 | 持ち場4マス内への侵入で覚醒。持ち場6マス内で追跡し、味方が6＋自身の射程外へ離れると帰還。帰還完了で待受へ |
| 局所守備 | 指定半径内で攻撃し、対象がなければ持ち場へ。通常前衛1マス、後衛2マス、守将0マス。非致死の集中を既存lineと同様に抑制 |

01は進軍2／迎撃1／守備3。04は進軍2／迎撃4／守備6／現行1。04の `extra-3-0-3` は既存holdのまま（限定側面迂回は未実装）。守将は城上を離れない。

途中のcheckpointで役割を変更し、敵が新しい持ち場の外にいる場合は、既存距離場で合法な帰還を行う。帰還途中にまだ守備域へ到達できなければ域外で攻撃しない。目標マスが埋まっていれば近くで待ち、経路不能なら待機。戦闘ルール・地形・HP・雨・P3・保存形式は共有し、変更しない。

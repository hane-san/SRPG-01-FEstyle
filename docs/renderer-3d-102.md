# 3D試遊レンダラの技術設計（#102 / #104）

基準：origin/main `44d0d0d`。この設計を実装より先にコミットする。
対象は試遊01/04、industrial/fantasyの`renderer=webgl`のみ。本編と既定の試遊は2D。
最新の手動依頼ではPR・CI後の通常マージと公開確認まで許可された。恒久の運用設定は変えない。

## 境界と時計

- `renderer-3d.js`はstateと表示用viewを読む。engineへ命令しない。経路・移動コスト・射程・ダメージ・勝敗を計算しない。
- 移動・向き・関節は既存playbackの`animation.segment/progress`、`motion`、`strike/projectile`を読む。命中・盾受け・回復・撃破は`impact/jewel/ghost`を読む。独自の演出タイマーや音源を作らない。
- #101の数字→拡大宝石→実HPぶんの破砕、P2の一拍、HP1警告を共有。宝石/数字の既存描画関数を画面座標へ配置し、WebGLの深度に隠さない。Fast/Reducedは既存時計をそのまま受け、Reducedでは歩行揺れ・呼吸・反動を止める。
- 待機呼吸のみappの既存125ms再描画に載せる。背景では描画せず、復帰時は最新state/viewを再描画する。音楽No.43–46と`music=fixed`は既存実装を使い、音楽コードは変更しない。

## 投影・指示点・表示高さ

- 北上固定、正投影、真上から約30度傾ける。Xを水平、北→南のZを画面下へ投影。自動回転・演出ズームはない。
- `projection-3d.js`で同じ4×4 view-projection行列と逆行列を保持する。`cellToScreen`はその行列で地面/頭上を投影。`screenToCell`は逆行列でnear/farの光線を作り、セルの地面平面と交差する。clientX÷tileの代用は禁止。
- 通常地面・水面・橋天面の高さを`surfaceHeight(map,cell)`で一意に定義し、造形・駒の足元・経路・ray pickingが共有。高さは表示だけ。地形コストや通行可能性はengineが決める。装飾の木や城壁は指示面にしない。
- 飾りメッシュを触っても所属セルへ対応するよう、投影された駒の上半身の狭い候補領域を先に判定し、密集時は画面距離と深度で一意に選ぶ。44pxのUIボタンは維持し、盤面セルへ重複する44px矩形を敷き詰めない。
- ネイティブのスクロールで盤面をパンする。3Dのcanvasも全盤面の投影サイズを持つ。中心セルを逆投影して保存し、2D/3D切替・ズーム・回転後は新しい投影で同じ中心へ戻す。試遊で初めて3Dを有効化すると共有スクロール面に半viewportの余白を確保し、マップ端でも切替前の中心を保持できるようにする（整数scrollによる1px未満の丸めは許容）。通常の自軍への移動は従来同様マップ端へ収める。本編と未使用の2Dはこの余白を作らない。scroll数値の一致は要求しない。

## 画面と切替

- 既存Canvas2Dは2D時に従来の二層32pxキャッシュを使用。3D時だけ、隣接するWebGL canvasと透明なCanvas2Dオーバーレイへ分担。dockのDOM・寸法は触らない。
- 頭上に兵種・所属・行動済・HP6を共通表示。樹冠/城壁は駒に隣接する面を低くし、頭上表示は最後に画面へ描く。選択/経路/射程はengine/ui-modelの結果を投影する。
- 比較メニューに2D/3Dを追加。style切替は同じ状態・中心・選択・ドラフトを保ち、3D2案は同じ投影。指保持/演出ロック中の切替は拒否する。URLは試遊内の表示選択だけを変え、セーブへ書かない。
- 使用不能/描画失敗/context lost時は理由を短く表示して2Dへ戻す。表示例外でplaybackを中断しない。確定済み最終状態への収束は既存playback/appが所有。context restoredで自動的に3Dへ戻さず、次の明示切替で再構築する。

## GPU・CPUの上限と解放

- WebGL1、外部ライブラリ/素材/CDNなし。頂点色+法線による面の照明、正投影、深度テスト。影は足元の手続きメッシュで、shadow mapは作らない。
- 同時に1 context、1 program、2 vertex buffer（静的地形/動的駒）、アプリ所有texture/FBO/renderbufferは0。上限は静的240,000頂点、動的120,000頂点、合計120,000三角形。各頂点は位置/法線/色の9 float、GPU頂点メモリ上限12.96MB。canvas DPRは最大1.5、背面寸法は最大4096px/辺、背面画素は最大2,097,152。MSAAなし。既定色+深度を8bytes/画素で見積もると約16.8MBで、ブラウザ/ドライバ自身の複製・compositorメモリは別であり全GPUメモリの保証値ではない。
- 地形メッシュはmap/style/選択近傍の遮蔽キーが変わった時のみ再構築。駒メッシュは同じ動的bufferへ上書き。毎フレームbuffer/programを新規作成しない。2D切替でbuffer/programをdeleteし、canvas/contextは1個を再利用する。context lossで旧ハンドルを破棄し復帰時に二重deleteしない。
- 静的/動的の最大2 draw callsを基本とし、Canvas2D overlayは別に数える。上限を超えた場合は切り捨てず理由を表示して2Dへ戻す。初期描画・CPUフレーム時間・頂点/三角形・draw calls・資源数をdebug計測口へ記録する。GPU完了時間や実機60fps保証とは扱わない。

## 代表造形

industrialは鋲打ち鋼板、桁橋の斜材、配管の曲がりと継手、真鍮の装甲縁、ランプ、護岸。fantasyは不規則な岩の面、積層した石壁、幹と複数の樹冠、瓦/木/土の接地を作る。共通の配色だけの交換にはしない。
兵は頭/胴/脚/腕/武器を関節で組み、重装の板盾、馬体+4脚+騎手、弓の両腕と弦、治療杖、砲架+車輪+砲身、軽装の刃、賊の覆面と曲刀を区別する。これは手続きポリゴンによる最初の可遊版で、写実美術の完成を自動テストで宣言しない。

## 受入

Nodeで行列往復・橋高さ・境界・姿勢の純粋性・メッシュ上限を検査。ブラウザで01/04×2テーマ×4画面×通常/Fast/Reduced、実タッチの出撃/選択/敵フリック/静止治療/ターン終了、切替/背景/context loss、同一命令の最終state・音楽/本編保存の不変、数字と実HP破砕数、資源数を検査する。
`npm run check`と全ブラウザスイートを実行。engineは変更しない。性能とスクリーンショットを測ってPRへ記録する。iPhone/WebKit実機、独立監査、造形/見た目/狙いやすさの人間評価は未検証として残す。

## 再現した不具合と修正

**P3温存時の誤った支援表示（medium、自己確認）**

1. 弾薬のある砲兵を、射程内に敵がいる状態で選択する。
2. 「詳細」→「消費許可：ON」を押して温存へ切り替える。
3. 修正前は、実際のP3は発動しないのに敵上にP3札が残り、命令欄もP3攻撃を案内した。

原因は、描画条件と盤面キャッシュキーが既存の`spend`を見ていないこと。札を既存の消費許可に連動させ、待機前・待機済み双方の短文も「弾薬温存・P3なし」に合わせた。`engine.js`・ダメージ・兵種・弾薬消費・保存キー/形式・マップは変更していない。読み込みタグを更新し、古い表示キャッシュを再利用させない。

回帰は実際の詳細ボタンでON→温存→ONと切り替え、同じ選択部隊の札が消える/戻ること、治療役にも同じ規則が働くこと、カメラ/dock寸法が不変であることを確認する。修正前の失敗は`no support badge while ammunition is being conserved`。
